# outputs 目录说明

对外可查看的产物区。

| 目录 | 用途 |
|------|------|
| `final/` | 已确认、可交付、可展示的最终产物 |
| `drafts/` | 可展示但未定稿的产物 |
| `samples/` | 当前样例、演示样例、标准示例 |
| `test-results/` | 测试产物、测试截图、测试报告 |
| `archive/` | 旧版产物、历史交付物 |

命名建议：

```text
20260603-T001-test-result-chat-logger-v01.md
20260603-M1-sample-email-parser-v01.json
20260603-FINAL-final-skill-package-v01.zip
```

清理提示：

- `final/` 和 `samples/` 不要清理。
- `drafts/` 可保留最近 1-3 个版本。
- `test-results/` 的旧文件在测试记录完成后可清理或归档。
