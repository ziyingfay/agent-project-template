## 001 | YYYY-MM-DD | 建立

**类型：** 建立  
**决策方：** User + Codex  
**状态：** Confirmed

**内容：**

初始化项目工作区规范：

- `AGENTS.md` 定义 Codex 工作规则
- `dev/docs/` 保存正式过程文档
- `dev/notes/` 保存工作日志和聊天记录
- `reference/` 保存参考资料
- `app/` 保存正式代码
- `outputs/` 保存对外交付物

**原因：**

让项目在多轮对话、多阶段开发中保留上下文、可追溯决策、可复查测试与问题状态。

## 002 | 2026-06-03 | 增强

**类型：** 增强  
**决策方：** User + Codex  
**状态：** Confirmed

**内容：**

将 `dev/docs/文件管理规范.md` 融入内置 `skills/active/project-management/SKILL.md`，让文件管理不只是参考文档，而成为项目管理 skill 的实际执行流程。

具体增强：

- 新增 Mandatory Artifact Workflow：分类产物、选择目录、生成文件名、保存/移动、记录、清理提示
- 新增 Cleanup Procedure：清理前分类为 safe-to-clean / confirm-first / do-not-clean
- 新增 Phase Integration：Intent、Skill Design、Build、Test、Package、Review 各阶段都纳入文件管理要求
- 统一 skill 输出目录为 `skills/active/<skill-name>/`
- bootstrap 脚本会复制内置 project-management skill 到新项目

**原因：**

同事不熟悉工程目录时，需要通过二级目录和文件名快速判断文件性质、来源、版本、能否清理。将规范写入 skill 可以确保 Codex 在实际工作中主动执行，而不是只把规则留在文档里。
