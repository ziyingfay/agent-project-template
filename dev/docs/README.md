# dev/docs 使用指南

本目录保存项目的正式过程文档，用于让 Codex 和项目成员恢复上下文、追踪决策、检查问题和验证结果。

## 文档索引

| 文档 | 用途 | 更新时机 |
|------|------|---------|
| `../current-state.md` | 当前阶段、当前焦点、下一步 | 每次阶段或焦点变化时 |
| `项目管理文档.md` | 项目目标、职责、流程、里程碑 | 流程或计划变化时 |
| `需求变更日志.md` | 需求、澄清、关键决策的单一事实来源 | 每次关键决策后 |
| `问题跟踪.md` | bug、风险、调查项和修复状态 | 发现/修复/验证问题时 |
| `测试记录.md` | 自动/手动测试记录 | 每次测试后 |
| `里程碑检查清单.md` | 阶段验收标准 | 开始或完成里程碑时 |
| `系统结构.md` | 架构、目录、页面、API、数据关系 | 结构变化时 |
| `Skill开发说明.md` | Agent skill 的轻量开发流程和规格模板 | 创建/修改 skill 时 |
| `文件管理规范.md` | 二级目录、命名、清理规则 | 创建/移动/清理文件时 |

## 新会话恢复上下文

1. 读 `dev/current-state.md`。
2. 读 `需求变更日志.md` 最近 3-5 条。
3. 读最新的 `dev/notes/work-log-*.md`。
4. 查看 `问题跟踪.md` 中 Open / In Progress 项。
5. 创建或修改 Agent skill 时，查看 `Skill开发说明.md`。
6. 创建、移动、归档或清理文件时，查看 `文件管理规范.md`。
