## Skill 包结构

```text
skills/<skill-name>/
├── SKILL.md
├── scripts/
├── references/
├── assets/
└── examples/
```

| 文件/目录 | 用途 |
|-----------|------|
| `SKILL.md` | skill 的核心说明和执行流程 |
| `scripts/` | 可复用脚本 |
| `references/` | skill 专属参考资料 |
| `assets/` | 模板、图片、静态材料 |
| `examples/` | 输入输出样例 |
