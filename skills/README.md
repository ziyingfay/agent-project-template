# skills 目录说明

Agent skill 的主要交付区。

| 目录 | 用途 |
|------|------|
| `active/` | 当前可用或准备交付的 skill |
| `drafts/` | 未定稿 skill 草稿 |
| `examples/` | skill 使用样例 |
| `test-fixtures/` | 测试输入和测试夹具 |
| `archive/` | 旧版本和废弃版本 |

内置管理 skill：

- `active/project-management/`：项目管理、文件管理、状态恢复、测试记录和归档规则。

命名建议：

```text
YYYYMMDD-TASK001-draft-skill-name-v01.md
YYYYMMDD-T001-fixture-skill-name-v01.json
```
